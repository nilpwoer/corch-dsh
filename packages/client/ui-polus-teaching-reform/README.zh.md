# 教学改革访谈工作台

[English](README.md) | 中文

客户端插件准备专家信息和带版本的问题包，并发布到显式配置的 Worker。本地访谈资料保留在浏览器中；Worker 管理参与者会话、执行设置和报告。配置在安装 `dsh-better-sidebar` 的同时挂载本插件包。

## 发布与分享

在访谈设置中保存 Worker 地址及其管理端「发布 API Key」页面创建的 Key。本机回环地址之外必须使用 HTTPS。Windows 桌面端使用当前系统账户加密 Key；浏览器仅保存非敏感目标和授权元数据。纯浏览器客户端会提示更新桌面端，不打开登录窗口。模型提供方的凭据单独配置。

校阅当前问题后点击「发布并打开 SPA」。原生进程立即上传、校验对应回执并打开参与者页面，无需第二次确认或管理员登录。缺少、过期、撤销或无效的授权会显示中文行内错误和设置入口。重复点击合并为一次请求；失败或取消后可以重试相同的不可变内容。内容变化需要新版本，未改变内容的保存保留版本号。显示状态以当前版本的成功回执为准。

新发布内容不包含访问口令。Worker 在分享链接的片段中返回邀请口令；参与者页面消费并移除片段后直接进入。原生预览请求新访谈，刷新保留本次冻结会话。浏览器保存分享回执，绝不包含发布 Key。获得完整链接的人也获得访问口令。

问题包工具栏提供 JSON 下载和新版本操作；地址框图标复制完整分享链接并提示成功。题包默认每题最多追问两次，并携带题目输入策略：纯选择题不追问；条件“其他”须同时选中且填写文字。Worker 默认继承题包策略，管理员可保存 0–2 次、每题或整场计数的覆盖。修改仅影响新访谈，同版本上传保留独立覆盖。参见 [Worker 设置](../../../worker/README.zh.md#management-settings-and-interview-freezing)。

问题包 JSON 的文本字段拒绝对象和数组，不将其转换为展示文字。每道专家题均常驻显示文字框。生成、Markdown 转换、编辑与发布将控件统一为 `text`（无选项）或 `mixed`（辅助选项），仅保留实质回答选项。“其他/请补充”及“不适用/暂不适用/暂不使用”等兜底控件不作为选项，叙述与补充均在常驻文字框填写。过滤依据完整控件标签及实际变体，不删除包含这些词的业务文字。旧存储模式仍可读取；专家渲染规则也适用于已发布题包及恢复中的访谈。更新 Worker 可执行程序与 HTML/JS 资源、刷新专家页面后，旧题包直接生效，无需重新发布、安装客户端或迁移数据库。新的生成与编辑行为需要更新客户端资源。历史回答、会话和固定追问上限保持不变，包括零次限制。参见[叙述输入决策](../../../.agents/notes/implemented/bug-fix/2026-10-20-always-visible-expert-input.zh.md)。

## JD 搜索

JD 模型通过原生 `web_search` 发现候选链接，只保留本次搜索工具元数据中存在的 URL。候选来源先存档，再由桌面浏览器采集；候选链接本身不能证明取得原文。Host 限制所有已存档 JD 会话，仅在 `/jd/discovery-begin` 与 `/jd/discovery-end` 之间允许搜索，`maxDiscoveryCalls` 默认每次五次。匿名 `web_fetch`、Shell 及其他工具始终被拒绝，覆盖恢复的会话与迟到调用；普通访谈沿用自己的工具策略。外部搜索提供者自行控制其爬虫，客户端的平台限速只约束本机浏览器访问。参见[浏览器采集决策](../../../.agents/notes/implemented/feature/2026-10-23-browser-first-jd-collection.zh.md)。

## JD 研究项目

每次新建搜索立即建立独立 DSH 会话与 Host 项目，保存到 `DSH_HOME/jd-projects`。侧栏列出搜索存档，切换时还原目标草稿、筛选、采集文本、当前步骤及所选图谱版本；历史导航前先保存待写入内容。重复已执行搜索会复制条件并另建记录。原子写入、写锁与乐观修订避免覆盖。仅本机同源访问的 `/jd` 通道提供 list、read、save、confirm、confirmed 和 export。`projectDirectory` 可指定目录，`maxProjectBytes` 默认 20 MiB；既有格式一项目仍可读取。原文与图谱版本只能追加；剔除影响后续生成，旧图谱保留原始语料。

桌面端使用共用的持久化浏览器会话，逐条渲染候选页面。公开 JD 无需登录，各平台分别复用自己的 Cookie，跨项目和重启保留。打开所选来源会启动被动页面监测。普通登录后出现完整可读 JD，自动采集并保存到发起搜索，无需点击继续、不切换当前搜索，也不调用模型。登录表单、部分正文登录墙及验证页不能触发保存，仍可手动采集。平台状态区分页面可读取、需要登录、缓存可用与访问受限。安全验证或 HTTP 429 会持久化停止该平台的自动请求、跳转、弹窗和后台访问。**处理平台验证**明确开放人工验证窗口；恢复操作只检查当前页面，取得有效 JD 后才解除停止，安全验证后即使正文可读，仍需明确确认恢复，自动登录采集不能解除平台停止。不自动跳转或重试。登录不能保证访问成功。限速、缓存设置及数据位置见[桌面指南](../../../apps/desktop/README.zh.md)。普通浏览器只保留候选来源，不静默回退 HTTP。用户取得有权使用的正文后，可粘贴或导入 `.txt`/`.md` 并填写来源 URL，保留手工来源标记；文件选择支持键盘操作、同文件重选和文件名预览，大小上限 1 MB。

自动采集结果先写入私有原生投递队列，Host 保存项目后才确认完成。应用不依赖工作台是否打开来处理队列，页面刷新或重启后也会重放；与草稿自动保存共用项目写入器，保留所属会话。重复投递幂等，保存失败保留待重试。

来源保留 URL、采集时间、方式和 SHA-256。BOSS 列表详情须匹配唯一的同源详情链接与岗位名称，或使用独立详情页；详情 URL 不保留查询参数及片段。浏览器原文保存渲染后的文本而非 HTML 字节，截断结果、登录页与验证页不会作为原文。搜索日期与地区是条件，不代表每份来源已核验。五级图谱拒绝不完整层级、无依据的直接陈述及原文中不存在的引文。引文覆盖描述冻结样本，不是市场总体占比；推断的流程、知识与评价仍明确标记待专家审核。

单一图谱步骤先提供**确认能力图谱**。Host 保存不可变版本及确认时间，供课程建设后续使用；`/jd/confirmed` 列出项目和版本标识，读取项目即可取得冻结图谱与原文。确认不代表专家背书，新版本需单独确认。只有已确认版本显示**导出 HTML**，Host 拒绝导出未确认版本。报告含封面、目录、五级树、证据主表及来源附录，保留逐字引文、链接和完整原文哈希。确认、恢复和导出不调用模型。Windows 将 HTML 保存到 `data/exports` 后调用系统浏览器，打开失败则显示文件所在目录；报告禁用脚本与联网。纯浏览器导出会下载 HTML，需从下载目录中打开。参见[已确认工作台决策](../../../.agents/notes/implemented/feature/2026-10-23-confirmed-jd-workspaces.zh.md)。

## 模型体验

### 问题包生成

#### 模型所见

生成操作读取“专家访谈 → 访谈设置 → 系统提示词”保存的全局模板，渲染后通过当前会话的 `session.prompt` 作为用户消息提交。该字段控制问题包生成，不改变 Host 系统消息角色或 Worker 的追问、报告提示词。专家字段、补充资料及启用文献摘录替换已说明的变量，已保存模板若缺少必需的回答模式协议，渲染请求会补上该协议；已生成题包保留原内容。

#### Token 影响

客户端内置所提供的 14 份 Markdown。全文检索与预览读取真实正文；启用来源仅向生成上下文提供有预算限制的原文摘录及原文件行列定位，题包元数据保留文件摘要和摘录并随发布传递。内置文献上下文总量低于 42,000 字符。用户正文、标题与启用、归档选择优先，不被种子更新覆盖。缺少正文明确报错；OCR 书目信息未经核实，Markdown 定位不代表纸书页码。生成追加渲染后的用户消息；发布和设置不调用模型。

#### KV Cache 影响

生成追加会话历史，未改变的前缀按提供方行为继续复用。发布与设置不发送模型请求。

### JD 推理、搜索与分析

#### 模型所见

岗位推理接收专业和可选方向；搜索接收岗位名称、平台、区域、发布时间范围及条数上限，返回候选链接 JSON。搜索摘要只作为发现线索，不能代替 JD 原文。图谱生成接收保留的 JD 原文、来源编号和哈希，返回项目 → 任务 → 流程 → 技能点 → 知识点节点、逐字引文、直接依据／推断标记，以及明确标为推断的评价建议。这些输入作为用户消息进入所属会话，不包含 Worker 发布凭据或私人专家记录。

#### Token 影响

推理、搜索与分析是独立模型操作。原生网页搜索产生额外提供者调用并增加发现元数据；浏览器采集不调用模型。图谱生成时保留的 JD 原文增加上下文。图谱确认和 HTML 导出读取已保存数据，不调用模型。五条测试档是上限，不能保证数量。来源匹配、剔除及结果展示不额外调用模型。

#### KV Cache 影响

各操作追加到同一所属会话，可以复用未变前缀；新 JD 会话拥有独立历史。


## 已知限制与待办事项

- 原生发布需要新版桌面发布接口和支持上传 Key 的 Worker。[Loader 验收](../../../apps/web/tests/worker-publication.e2e.ts) 使用 `DSH_WORKER_SIDEBAR_PACKAGE`；[原生验收](../../../apps/desktop/publisher-ui.acceptance.mjs) 使用实际 EXE 和隔离 Worker HTTP/页面。SQL 验收单独检查数据库存储与迁移。合成替身不能证明真实模型质量或麦克风通过验收。[授权决策](../../../.agents/notes/implemented/feature/2026-10-16-worker-publisher-keys.zh.md) 记录凭据权限与回退限制。
