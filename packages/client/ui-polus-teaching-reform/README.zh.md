# 教学改革访谈工作台

[English](README.md) | 中文

该客户端插件准备专家资料和版本化题包，再将已确认题包发布到显式配置的 Teaching Worker。 既有访谈资料保留在浏览器中；Worker 管理参与者会话、执行配置和已保存报告。

Profile 需要同时挂载本包的 [bundle 补丁](cordis.patch.yml)和已安装的 `dsh-better-sidebar` 服务。默认 Web bundle 不挂载本工作台。真实 Loader 验收使用 `dsh-better-sidebar@0.17.1`、一次性 profile 和宿主会话。

## 发布与分享

在访谈设置的 **Worker 发布** 中保存 Worker origin。公开目标必须使用 HTTPS；只有回环开发地址 可使用 HTTP。地址不能包含凭据、路径、查询或片段。系统不推断或静默配置目标。

确认题包，再选择 **发布并打开 SPA**。Worker 会打开自己的 管理窗口。使用既有账号登录，在窗口内核对题包键、专家、版本和题目数量，明确确认上传。DSH 收到匹配的成功回执后才标记已发布。关闭、取消、登录失败或上传失败后均可重试。同版本使用 稳定的发布字节实现幂等重试；内容变化时需选择 **创建新发布版本**。该操作不会重新生成题目或 调用模型。

SPA 预览仅包含访谈口令和分享链接。链接携带不可变题包键及片段中的口令。Worker 将口令从浏览器 历史中移除、预填，并等待参与者点击进入。收到完整链接的人也会收到该邀请口令。

## Worker 配置

管理端提供追问和报告各阶段的全局业务提示词、每题包覆盖，以及每题包的追问范围和次数。 继承关系和执行冻结语义见 [Worker 参考](../../../worker/README.zh.md#management-settings-and-interview-freezing)。 同版本再次发布不会替换独立的 Worker 配置。新题包及新版本不携带初始追问策略，需在参与者进入前由 Worker 管理端配置范围和次数。访谈标题提供发布目标；既有保存的目标及同版本旧策略保持稳定，以兼容发布重试。JSON 下载与新版本操作位于问题包操作栏，DSH 不提供发布设置表单。

## 模型体验

### 题包生成

#### 模型可见内容

生成操作通过 `session.prompt` 将[渲染后的访谈提示词](src/client/interviewPrompt.ts)提交给既有 Agent，其中包含保存的方法模板、专家资料、提供的专家材料和加载的全局参考资料。发布、创建新发布版本、编辑 Worker 设置和读取已保存报告均不发起模型请求。

#### Token 影响

生成时将渲染后的提示词作为排队的用户消息加入会话，长度取决于模板、专家资料及提供的材料。发布和 Worker 设置操作不增加模型输入 Token。

#### KV Cache 影响

生成会追加既有会话历史，未改变的请求前缀是否可复用由服务决定。发布和设置修改不发送请求，不影响该缓存。受控替身不能证明真实模型或麦克风已验收。

## 已知限制与延后工作

- 直接发布目前仅接受回环 DSH origin，需要允许弹窗并使用既有 Worker 管理员登录。此功能不创建持久发布凭据，也不放宽 Worker CORS 或认证。[真实 Loader 验收](../../../apps/web/tests/worker-publication.e2e.ts)需要用 `DSH_WORKER_SIDEBAR_PACKAGE` 指向已安装的侧栏插件、用 `DSH_WORKER_PUBLISH_FIXTURE` 指向一次性 Worker 的私有交接文件；缺少这些输入时，相应检查会跳过。验收使用合成数据，不调用模型。操作系统原生输入法、麦克风和真实模型仍需另行验收。
