# 教学改革访谈工作台

[English](README.md) | 中文

客户端插件准备专家信息和带版本的问题包，并发布到显式配置的 Worker。本地访谈资料保留在浏览器中；Worker 管理参与者会话、执行设置和报告。配置在安装 `dsh-better-sidebar` 的同时挂载本插件包。

## 发布与分享

在访谈设置中保存 Worker 地址及其管理端「发布 API Key」页面创建的 Key。本机回环地址之外必须使用 HTTPS。Windows 桌面端使用当前系统账户加密 Key；浏览器仅保存非敏感目标和授权元数据。纯浏览器客户端会提示更新桌面端，不打开登录窗口。模型提供方的凭据单独配置。

校阅当前问题后点击「发布并打开 SPA」。原生进程立即上传、校验对应回执并打开参与者页面，无需第二次确认或管理员登录。缺少、过期、撤销或无效的授权会显示中文行内错误和设置入口。重复点击合并为一次请求；失败或取消后可以重试相同的不可变内容。内容变化需要新版本，未改变内容的保存保留版本号。显示状态以当前版本的成功回执为准。

新发布内容不包含访问口令。Worker 在分享链接的片段中返回邀请口令；参与者页面消费并移除片段后直接进入。原生预览请求新访谈，刷新保留本次冻结会话。浏览器保存分享回执，绝不包含发布 Key。获得完整链接的人也获得访问口令。

问题包工具栏提供 JSON 下载和新版本操作；地址框图标复制完整分享链接并提示成功。题包默认每题最多追问两次，并携带题目输入策略：纯选择题不追问；条件“其他”须同时选中且填写文字。Worker 默认继承题包策略，管理员可保存 0–2 次、每题或整场计数的覆盖。修改仅影响新访谈，同版本上传保留独立覆盖。参见 [Worker 设置](../../../worker/README.zh.md#management-settings-and-interview-freezing)。

生成的每题声明 `answerMode`：`text`（仅文字、无选项）、`choice`（仅选择）、`mixed`（选项加常驻输入框）或 `other`（选中其他后输入）。主持人编辑器在保存、刷新与发布时保留该选择；有文字输入的题仅依据实际文字、每题最多追问两次。缺少字段的记录保持旧行为。修复已保存混合题时，选择模式并发布新版本供新访谈使用，固定版本的已有访谈不变。显式模式需要配套更新客户端与 Worker，无需数据库迁移。参见[回答模式决策](../../../.agents/notes/implemented/feature/2026-10-20-explicit-interview-answer-modes.zh.md)。

## 模型体验

### 问题包生成

#### 模型所见

生成操作读取“专家访谈 → 访谈设置 → 系统提示词”保存的全局模板，渲染后通过当前会话的 `session.prompt` 作为用户消息提交。该字段控制问题包生成，不改变 Host 系统消息角色或 Worker 的追问、报告提示词。专家字段、补充资料及启用文献摘录替换已说明的变量，已保存模板若缺少必需的回答模式协议，渲染请求会补上该协议；已生成题包保留原内容。

#### Token 影响

客户端内置所提供的 14 份 Markdown。全文检索与预览读取真实正文；启用来源仅向生成上下文提供有预算限制的原文摘录及原文件行列定位，题包元数据保留文件摘要和摘录并随发布传递。内置文献上下文总量低于 42,000 字符。用户正文、标题与启用、归档选择优先，不被种子更新覆盖。缺少正文明确报错；OCR 书目信息未经核实，Markdown 定位不代表纸书页码。生成追加渲染后的用户消息；发布和设置不调用模型。

#### KV Cache 影响

生成追加会话历史，未改变的前缀按提供方行为继续复用。发布与设置不发送模型请求。

## 已知限制与待办事项

- 原生发布需要新版桌面发布接口和支持上传 Key 的 Worker。[Loader 验收](../../../apps/web/tests/worker-publication.e2e.ts) 使用 `DSH_WORKER_SIDEBAR_PACKAGE`；[原生验收](../../../apps/desktop/publisher-ui.acceptance.mjs) 使用实际 EXE 和隔离 Worker HTTP/页面。SQL 验收单独检查数据库存储与迁移。合成替身不能证明真实模型质量或麦克风通过验收。[授权决策](../../../.agents/notes/implemented/feature/2026-10-16-worker-publisher-keys.zh.md) 记录凭据权限与回退限制。
