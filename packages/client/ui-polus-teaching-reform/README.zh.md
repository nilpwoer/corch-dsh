# 教学改革访谈工作台

[English](README.md) | 中文

客户端插件准备专家信息和带版本的问题包，并发布到显式配置的 Worker。本地访谈资料保留在浏览器中；Worker 管理参与者会话、执行设置和报告。配置在安装 `dsh-better-sidebar` 的同时挂载本插件包。

## 发布与分享

在访谈设置中保存 Worker 地址及其管理端「发布 API Key」页面创建的 Key。本机回环地址之外必须使用 HTTPS。Windows 桌面端使用当前系统账户加密 Key；浏览器仅保存非敏感目标和授权元数据。纯浏览器客户端会提示更新桌面端，不打开登录窗口。模型提供方的凭据单独配置。

校阅当前问题后点击「发布并打开 SPA」。原生进程立即上传、校验对应回执并打开参与者页面，无需第二次确认或管理员登录。缺少、过期、撤销或无效的授权会显示中文行内错误和设置入口。重复点击合并为一次请求；失败或取消后可以重试相同的不可变内容。内容变化需要新版本，未改变内容的保存保留版本号。显示状态以当前版本的成功回执为准。

新发布内容不包含访问口令。Worker 在上传回执中返回参与者口令和只在片段中携带口令的分享链接。浏览器保存该回执以便显示、复制，绝不包含发布 Key。既有口令保留用于原版本字节不变的重试，新版本省略它。获得完整链接的人也获得访问口令。Worker 从历史中移除片段并填入口令，等待参与者进入，不自动开始访谈。

问题包工具栏提供 JSON 下载和创建新版本操作，预览提供口令与链接。追问范围、次数和提示词继承或覆盖由独立的 [Worker 编辑器](../../../worker/README.zh.md#management-settings-and-interview-freezing) 管理。新题包不推断策略，进入访谈前必须有显式题包策略或保存的覆盖设置。同版本上传保留独立 Worker 设置，报告使用单独的管理页面。

## 模型体验

### 问题包生成

#### 模型所见

生成操作通过现有会话提交[渲染后的访谈提示词](src/client/interviewPrompt.ts)，包含专家信息、所附资料和启用文献。发布、编辑、设置与查看报告不发起模型请求。

#### Token 影响

生成追加渲染后的用户消息，大小取决于所附信息。发布与设置不增加模型输入 Token。

#### KV Cache 影响

生成追加会话历史，未改变的前缀按提供方行为继续复用。发布与设置不发送模型请求。

## 已知限制与待办事项

原生发布需要新版桌面发布接口和支持上传 Key 的 Worker。[Loader 验收](../../../apps/web/tests/worker-publication.e2e.ts) 使用 `DSH_WORKER_SIDEBAR_PACKAGE`；[原生验收](../../../apps/desktop/publisher-ui.acceptance.mjs) 使用实际 EXE 和隔离 Worker HTTP/页面。SQL 验收单独检查数据库存储与迁移。合成替身不能证明真实模型质量或麦克风通过验收。[授权决策](../../../.agents/notes/implemented/feature/2026-10-16-worker-publisher-keys.zh.md) 记录凭据权限与回退限制。
