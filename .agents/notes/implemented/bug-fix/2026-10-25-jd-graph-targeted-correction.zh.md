# Agent Note: JD 图谱校验失败后的针对性纠错

Status: implemented

[English](2026-10-25-jd-graph-targeted-correction.md) | 中文

## 问题

模型完成的响应可以包含有效五级树与逐字引文，却把扩写说明标为原文直接依据。没有校验器给出的节点和字段诊断，重复同一指令可能一直产生相同错误，直至耗尽次数。按固定调用次数提供正确答案的模拟器，不能证明纠错信息传到了模型。

## 决策

首次图谱请求逐字使用现有基础提示词。未通过的响应产生新的已记录请求，保留同一基础提示词和冻结原文语料，并追加结构化校验反馈。反馈标识失败次数与类别。已解析图谱的诊断保留所有无效父级、不完整分支及无依据的直接声明，包含未修改的节点、出错字段、预期层级和已验证引文。JSON 格式错误及更早的字段或引文失败，返回对应类别或具体原因。所属会话保留被拒绝的模型响应，反馈不重复追加其整份图谱。

模型返回完整修正图谱。应用代码不修补节点、不转换依据标记，也不编辑引文来通过校验。每次新响应仍由同一校验器检查，通过后才可保存版本。配置次数上限、取消、请求失败、轮次完成、不可变版本及确认记录继续遵守[有来源依据的 JD 规则](../feature/2026-10-20-jd-search-integration.zh.md)。本记录只替代该记录中仅重复指令的重试决策，来源与持久化保证仍保持有效。

纠错反馈作为持久化用户消息中的模型可见数据，以 JSON 编码并标为校验数据，而非外部指令。追加请求继续使用已有的精确消息与轮次关联。基础提示词、原始证据、方法论及报告版式保持不变，不开放其他工具。

## 考虑过的替代方案

**只重复原始指令。** 没有解释具体失败声明，模型可能每次都产生相同错误。

**放宽直接依据匹配，或在应用代码中修改标记。** 这可能接受无依据陈述，或静默改变模型内容的作者归属。模型须纠正自身声明，并满足已有证据规则。

**追加整份被拒图谱。** 所属会话已经记录该响应，节点级诊断能用更少重复保留相关上下文。

## 影响

重试反馈在已有次数上限内增加上下文和普通模型用量，不能保证响应通过。耗尽次数保留既有版本、确认与原文。单元测试固定实际扩写说明失败、多项同时诊断、被拒输入不变以及请求取消。完整桌面模拟器只有收到各次错误对应的反馈，才能推进纠错，同时保留基础提示词及原文语料；缺失或不匹配的反馈不能产生通过的纠错记录。保留 JD 语料上的提供者行为仍须真实模型验收。
