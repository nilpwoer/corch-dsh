# Agent Note: 专家叙述输入框常驻显示

Status: implemented

[English](2026-10-20-always-visible-expert-input.md) | 中文

## Problem

已发布的专家题可能在选中“其他”后才显示回答框，或完全不显示回答框。教师需要先描述经验，再决定是否选择选项。只修复生成流程无法覆盖已发布题包与恢复中的访谈。

## Decision

每道专家题均常驻显示叙述输入框，包括旧 `choice`、`other` 和未声明模式的题包。生成、Markdown 转换、编辑与发布将控件统一为 `text` 或 `mixed`。仅保留实质回答选项。新题选项与专家页面过滤“其他/请补充”和“不适用/暂不适用/暂不使用”等兜底标签及已观察到的中文变体。叙述与补充均无需选择，直接填写常驻文字框。过滤针对完整控件标签形式，保留“其他部门协作”“不适用条款处理”等实质业务句子。Markdown 拆分保留括号说明，防止把业务文字拆成额外选项。

专家页面过滤标签时不重新编号原始选项。已提交与本地历史选择保持完整，包括过去选中的停用标签。Worker 允许旧 `none` 策略题提交结构化叙述文字，实际非空文字无需选择“其他”即可具备追问资格。快照哈希、题目策略、题包版本与冻结报告保持不变；固定的零次或更低追问上限仍然有效。选项成员校验、回答文字一致性与输入长度校验继续执行。

本记录部分替代[显式回答模式](../feature/2026-10-20-explicit-interview-answer-modes.zh.md)中的展示与生成规则。该记录继续说明兼容的发布格式及严格的模式、策略校验。不迁移任何已存题包、会话或回答。 本地预览仅在已存题包标识与完整题目都匹配加载题包时恢复草稿，防止跨题包复用回答。

## Alternatives considered

**重新生成或发布所有题包。** 无法覆盖恢复中的访谈，而且会产生不必要的新版本。运行时展示与提交兼容可直接修复现有题包。

**只修改页面。** 旧 `none` 策略会在提交时拒绝文字回答，服务端也必须接受新显示的叙述输入。

**从存储数组中删除停用标签。** 本地草稿可能引用选项索引，历史回答也可能包含该标签。展示隐藏控件，存储保留其身份。

## Consequences

更新 Worker 可执行程序及其 HTML/JS 资源、刷新专家页面后，已发布题包直接生效。这些题包无需更新客户端、重新发布、轮换口令或迁移数据库。新生成、编辑和本地预览行为也需要更新客户端资源。已完成报告保持只读，历史追问额度继续固定。

## Testing

客户端测试直接使用已发布题包的十九种标签原文及明确要求的变体，覆盖归一化、Markdown 转换、发布与真实无密钥 CLI 快照。Worker 测试覆盖旧选择题文字提交、历史选项保留、未知选项拒绝、独立叙述资格与既有追问上限。隔离浏览器使用合成数据、拦截全部网络请求，验证实际主持人 React 编辑器及专家脚本、桌面和手机布局、草稿与会话恢复。这些证据不代表生产部署或真实模型质量验证。
