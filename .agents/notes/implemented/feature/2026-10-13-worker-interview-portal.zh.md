# Agent Note: 固定发布版本的 Worker 访谈 Portal

Status: implemented

[English](2026-10-13-worker-interview-portal.md) | 中文

## Problem

DSH 发布包包含专家背景、元数据和可选题目提示，本地 preview DTO 无法直接导入。启动时的单包不能区分独立公开访谈，浏览器本地提交也不构成持久回答或报告。管理账号与题包上传需要服务端授权，但不应强制受访者注册。

## Decision

[portal 服务](../../../../worker/internal/service/portal.go) 在根路径及旧文件名提供既有 SPA 资产。独立 portal 配置保留回环 preview 限制。入口模式、邀请模式和报告可见性为明确可选参数，配置齐全前受访者路由保持关闭；实施测试不代替用户决定产品默认值。

[发布包模块](../../../../worker/internal/published/pack.go) 接受 DSH 字段，不要求槽位，保留可选 followUp 与 sourceRefs；portal 会话要求明确的题包追问策略。Engine 将目标、背景、回答历史和可选提示作为数据输入，可以认可充分回答而不生成另一道问题。调用模型前及最终事务内均检查已发布追问次数。

文件先校验，再原子发布，禁止同键不同内容覆盖。受根目录约束的文件操作拒绝越界路径和符号链接。MySQL 会话保存题包副本、版本、私有完整摘要与策略；浏览器绑定摘要排除邀请信息，因为短口令的快速摘要可用于离线猜测。移除目录题包不改变既有会话。

[管理服务](../../../../worker/internal/service/management.go) 使用数据库账号和可撤销会话，与访谈 Cookie 分离。首次初始化只在操作者提供强哈希时插入 admin，重启不覆盖密码，也不强制首次改密。准确来源校验、HttpOnly Cookie 和有限登录预算保护两种入口。报告正文受显式访谈可见性和管理登录控制。

[portal 验收](../../../../worker/portal_acceptance_test.go) 在隔离 MySQL 和可控模型下运行真实进程，覆盖版本 1 迁移、数据保留、凭据哈希、重启恢复、幂等、删除题包、报告访问与跨会话拒绝。浏览器场景验证上传、选项、可控语音入口、草稿刷新、真实回答请求、报告下载和退出。真实模型质量及麦克风支持不由测试替身证明。

[MySQL 租约决策](../architecture/2026-10-11-go-teaching-worker.zh.md) 保持有效，队列校验、版本捕获与报告证据职责继续保留；本文增加 portal 授权与多题包归属，不替换这些机制。

## Alternatives considered

- 复用公开 preview 路由会削弱明确的回环保证，portal 使用独立配置与会话命名空间。
- 仅把发布包保存在 localStorage 无法跨来源传递或在服务重启后保留已接收回答，因此文件承载发布包，MySQL 持有已接收状态。
- 服务器逐包上限及强制 required_slots 与题包次数、上下文 AI 判断冲突，因此策略明确，可选提示仍是数据。
- 新身份产品或复杂 RBAC 引入无关范围，因此最小管理账号使用现有 MySQL，受访者保持独立邀请/会话访问。

## Consequences

结构版本 2 在既有数据库锁内明确升级版本 1 并加入 portal 表；只有 admin 不存在时才需要私有初始化哈希。实施测试不创建真实凭据或公网部署。

DSH 增加 JSON 导出和明确的目标/策略输入，保留既有确认和发布操作。无策略旧包可检查但不能启动 portal 会话，多版本别名需要指定上传键。管理报告列表当前最多最近 200 个任务，未发送草稿保留在浏览器。
