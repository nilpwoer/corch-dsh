# Agent Note: 统一已保存报告预览与 PDF 下载

Status: implemented

[English](2026-10-14-worker-report-preview-pdf.md) | 中文

## Problem

参与者已有带证据链接的报告，但管理端仍展示原始 JSON，并将其作为报告下载。可读导出必须保留中文、长章节和证据，同时遵循已有访谈权限与保存版本。

## Decision

共享的无脚本 HTML 模板保留 Worker 报告的章节、陈述类型、任务卡字段和原文引用。参与者与管理端均嵌入该页面，并提供 PDF 下载。JSON 保留为内部 API 表示。读取时检查现有账号或访谈会话、参与者可见性策略和报告完成状态；可信后端路由沿用原有 Bearer 授权。

PDF 由固定版本的 gopdf 在进程内生成，嵌入采用 OFL 许可且已重命名的中文字体。文字可选择，所有段落按 A4 分页换行，引用批注跳转到对应证据。HTML 转义全部报告数据并设置严格 CSP。缺字时终止导出，避免静默丢字。查看和下载不调用模型，也不修改已保存的回答、发布版本或报告。

## Alternatives considered

**仅依赖浏览器打印**会打开打印流程，不能直接提供所需的 PDF 文件下载。**外部转换服务**会引入私有数据外发和额外运行依赖。**生产主机安装无头浏览器**会给旧版 Linux 增加安装及进程管理要求。**重新设计两套报告界面**会重复已有 Worker 排版，并使参与者与管理端逐渐不一致。

## Consequences

发布包随附字体和组件许可声明。二进制嵌入 HTML 与字体，生产环境无需 Chrome、Python、网络字体或 PDF 转换服务。参考字体的字形覆盖有限，不支持的字符会产生渲染错误，HTML 仍能展示原文。API-only 隔离验收使用已保存的合成报告，验证真实浏览器下载、中文长文分页、证据链接、转义、失败/空状态，以及匿名、跨访谈和可见性策略拒绝。报告渲染不需要模型调用。
