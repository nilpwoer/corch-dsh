# Agent Note: 搜索会话存档与已确认 JD 图谱

Status: implemented

[English](2026-10-23-confirmed-jd-workspaces.md) | 中文

## 问题

已保存的证据语料不能还原未完成的搜索。切换对话时丢失草稿字段、当前步骤或所选图谱，会让独立搜索看起来共用状态。课程建设使用生成初稿前，也需要明确、持久化的版本选择。

## 决策

每次新建搜索立即获得独立 Host 会话与项目文档。Host 拒绝同一会话下的第二个项目。重复已执行搜索会复制检索条件并建立新会话，不继承原文证据。客户端串行写入草稿、筛选、采集文本、当前步骤和图谱版本；通过搜索历史切换前等待待保存内容落盘。异步搜索结果始终归属于发起会话。

结构化工作台是 JD 对话的默认视图。私有插槽只渲染一个工作台实例；切换到原生运行记录或其他会话时释放该视图，返回后恢复同一项目写入器与草稿。原生消息和工具记录继续完整存档，并可按需查看，普通会话保留各自的对话视图。已保存原文和下一步操作位于工作台前部；失败来源、手动导入、技术元数据和帮助按需展开，安全验证暂停保留醒目的恢复入口。这些展示选择不改变证据、提示词或导出报告。

图谱生成创建不可变的初稿版本；确认是独立 Host 操作，使用权威时间戳与乐观修订校验。确认记录只能追加，重复确认保持幂等，新图谱版本需单独确认。仅本机同源访问的已确认列表提供项目和版本标识，供课程建设后续读取；确认不代表专家审核通过。原文证据、来源哈希和图谱验证仍由[有来源依据的 JD 决策](2026-10-20-jd-search-integration.zh.md)约束。

工作台只保留一个图谱步骤，主要操作先确认所选版本，再为该已确认版本显示 HTML 导出；Host 拒绝导出未确认版本。独立报告包含封面、目录、五级树、证据主表、来源链接和完整原文哈希，并明确标记推断。参考报告的样式不提供课程缺口、趋势或市场占比结论的证据。桌面端将报告保存到私有导出目录，以文件 URL 调用系统浏览器；打开失败则显示保存文件的位置。限制性内容策略禁用报告脚本和联网。

待采集来源的操作直接打开所选岗位，项目的平台窗口打开时显示继续采集。[浏览器采集决策](2026-10-23-browser-first-jd-collection.zh.md)约束自动渲染、会话复用、持久化平台停止及人工验证。用户能够通过正常浏览器取得有权使用的正文时，仍可手工导入并保留用户声明的来源标记；登录不保证解除平台限制。

## 考虑过的替代方案

**以模型对话作为研究的默认界面。** 原始协议 JSON 和重复采集诊断会遮住已保存原文与下一步操作；按需查看原生记录保留排查能力，不要求用户将其作为任务界面。**只还原最终结果。** 这保留了证据，却丢失未完成工作和所选历史版本。**生成即确认。** 这让待审初稿与选定供后续使用的版本无法区分。**图谱与导出分别设为步骤，并提供 MD/PDF 操作。** 两处重复展示同一图谱，也绕过了用户要求的确认顺序；报告以 HTML 分发，结构化数据留在项目中。**反爬后反复重试或伪装自动化访问。** 这不能证明可靠的平台兼容性，还可能加重访问限制，因此读取器明确报告受限状态。

## 影响

草稿字段和粘贴原文属于持久化私人数据，受项目大小限制。保存失败会阻止历史切换，不静默丢弃编辑。没有工作台状态或确认字段的既有格式一项目仍可读取。取得原文、确认及导出均不代表专家背书。定向存储、UI、原生测试和真实桌面装配快照覆盖独立会话、状态还原、不可变确认、确认前导出拒绝、来源归属、受限采集及 HTML 保存；合成验收证明应用行为，不证明 BOSS 可用性或模型质量。
