# Agent Note: 显式访谈回答模式

Status: implemented

[English](2026-10-20-explicit-interview-answer-modes.md) | 中文

## Problem

生成题目的选项也可用于辅助回忆，主回答仍可能是叙述。仅依据有无选项推导回答控件，会隐藏叙述输入框并将文字限制为选择“其他”后填写，与混合访谈方法不一致。

## Decision

新生成的每题声明 `answerMode`：`text` 常驻文字输入且无选项；`choice` 有选项而无文字输入；`mixed` 同时有选项和常驻文字输入；`other` 有选项，匹配“其他”选项后才显示输入框。`type` 保留题目主题与单选、多选信息。客户端拒绝不兼容或未知模式，在解析、编辑、浏览器持久化和导出中保留模式，并在发布时重新推导每题策略。已保存的自定义生成模板也会补充与默认模板相同的必需控件协议。

Worker 发布解析会依据选项与输入策略校验显式模式，拒绝缺失或矛盾的策略。文字与混合模式映射为 `input: text`，仅选择映射为 `none`，其他条件输入映射为 `other`。只有实际非空文字才具备模型追问资格，每题最多发布两次追问，并继续遵守既有更低上限。[访谈入口](2026-10-13-worker-interview-portal.zh.md) 保留固定题包及推导出的快照策略；展示修改不替换题包或快照数据。

缺少 `answerMode` 时保留按旧题型、选项推导的行为，包括已保存的其他条件输入策略。不会通过迁移重新解释现有发布或冻结访谈。主持人选择回答模式后发布新版本，可修复受影响草稿；已有访谈继续固定原版本，新访谈使用新版本。显式模式题包需要更新后的客户端与 Worker，旧 Worker 会拒绝未知字段。不需要数据库结构或凭据变更。

## Alternatives considered

**把所有含选项题视为选择题**会隐藏叙述回答。**把所有选择题改为混合题**会改变授权与纯选择语义。**仅修改 SPA 或提示词**会留下发布校验与模型资格不一致。**自动改写旧题包**会在未经主持人审核时改变固定访谈行为。

## Consequences

主持人可以保留辅助选项与自由文字，无需重新调用模型即可修复已保存草稿。客户端与 Worker 需要配套更新，新协议不会自动修复已经发布的版本。四种显式模式使输入框独立于模型自由填写的主题标签，仅对缺少新字段的记录保留旧行为。

## Testing

固定客户端数据覆盖解析、持久化与再次发布。实际 teaching-pack CLI 的快照在不访问模型供应商时覆盖四种模式。Worker 发布及引擎测试覆盖策略匹配、无效控件、冻结副本、条件资格和第三次追问拒绝。隔离浏览器场景挂载实际主持人编辑器和参与者资源，以合成 HTTP 响应验证模式编辑、刷新、混合文字与选项载荷及其他条件输入；不将其解释为真实模型质量或生产验收。
