# Agent Note: 内置专家访谈工作台的 Windows 桌面客户端

Status: implemented

[English](2026-10-14-windows-desktop-client.md) | 中文


## Problem

专家访谈工作台需要可分发的 Windows 应用，包含真实插件依赖并使用独立配置。浏览器快捷方式依赖另行启动的开发服务器；Python SDK 可执行文件构建器提供自动化代理，且不支持 Windows。

## Decision

仅当请求帧和顶层窗口都属于精确的本地后端 origin 时，允许剪贴板文本写入。拒绝剪贴板读取，以及 Worker 或外部来源的写入。工作台因此可以使用复制按钮，无需暴露 Electron 桥接或放宽渲染器隔离。

以最小 Electron 主进程承载正常构建的 DSH CLI/Web bundle。后端使用随包携带的官方 Node 运行时，确保原生扩展使用受支持的 Node ABI。生产闭包显式声明访谈插件和已打补丁的真实 better-sidebar 提供器。可写便携数据目录独立保存 Electron 配置、DSH_HOME 和工作目录，不接管已有 DSH_HOME，也不继承环境中的模型凭据。首次回环端口会保留，以维持按来源隔离的浏览器数据；已保存端口被占用时启动失败。

渲染页面禁用 Node 集成，启用上下文隔离和 Chromium 沙箱，导航限制在各窗口自身来源内。只有符合既有管理路径、回环发起来源及随机 nonce 的 Worker 发布弹窗可被创建。原生浏览器弹窗保留 `window.opener`、来源窗口身份和跨来源 postMessage 语义；仅受信本地工作台可使用受限的发布与 JD preload API；外部页面没有原生接口。Worker 主框架加载失败会关闭当前操作拥有的弹窗，让工作台显示可处理的错误，不增加原生上传确认。麦克风权限需原生提示确认。关闭应用通过私有 IPC 请求后端退出，等待进程结束，超时后的进程树终止仅针对自己创建的子进程；父进程断开也触发后端清理。

打包先核验固定官方运行时的 SHA256，在仓库 `.tmp` 下、发布目录之外的仅含发布文件工作区镜像中按冻结 pnpm 锁文件安装生产依赖，再物化共享工作区依赖图。载荷排除编译状态，检查拒绝链接及私人配置；压缩包包含逐文件清单和上游许可。桌面打包独立于常规库构建，不改变已经运行的客户端。

桌面后端在加载 CLI 前注册 Node 同步解析钩子。从其私有 DSH 主目录发起的导入和包元数据请求使用随包运行库中的内置包规范路径；额外的配置插件保留常规解析方式。启动回退检查发现清单已解析到规范安装路径时，不再创建别名。桌面启动不创建配置链接，也不替换已有的插件目录，因此支持目录联接创建失败的可写位置，并让插件共享同一份 Cordis。


桌面装配与教学插件使用目录／包名精确匹配的私有工作区策略，不声明上游 npm 发布元数据。品牌 SVG 和宠物 PNG 保留为显式发布资源。桌面依赖声明是冻结安装的根节点，包括通过配置而非静态导入访问的包。Knip 保留原生后端、preload 和验收入口，依赖例外仅作用于此装配。Electron 由固定运行时压缩包提供，Playwright 显式声明为开发依赖。闭包检查仍核验每个生产依赖及必需的 peer。

## Alternatives considered

**浏览器应用模式**依赖用户浏览器，不提供独立桌面运行时。**SDK 可执行文件**的协议和平台范围不同。**使用 Electron 内置 Node 运行后端**需要按其 ABI 重新构建原生依赖。**新增桌面 API 桥**会重复模型、配置和发布机制，同时增加权限。

## Consequences

便携包同时包含 Chromium 和受支持的 Node，体积较大。应用未签名，也没有自动更新；维护者需分发完整更新包并核对哈希。用户通过已有 DSH 设置初始化个人配置和凭据。回环提供商测试在无真实模型调用的情况下证明传输和凭据路由；真实模型质量、麦克风硬件和原生输入法仍需单独验收。桌面验收使用实际打包程序和隔离 Worker 合成题包，不冒用生产账号，也不写入生产发布记录。
