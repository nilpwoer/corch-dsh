# Agent Note: 有来源依据的 JD 搜索集成

Status: implemented

[English](2026-10-20-jd-search-integration.md) | 中文

## 问题

JD 工作台需要真实公开岗位正文。仅在基础 bundle 启用抓取仍会让浏览器会话缺少该工具，因为内置 Agent 预设拥有各自的工具注册。模型还可能引用与实际抓取页面不同的岗位编号，因此看似合理的链接与摘要不能证明来源。

## 决策

标准、代码和 Cordis 预设启用 `web_fetch`，使用 Host 的 HTTP 提供者。基础 importer 补充该 workspace 依赖，保留既有包解析。JD 岗位推理和搜索只使用其所属会话；切换会话重新挂载工作台，不复用其他会话的结果。结构化输出等待完整闭合的 JSON 对象，请求终止错误直接反馈到表单。

候选链接须与本次操作的真实 `web_search` 元数据匹配。候选地址、搜索摘要或模型描述都不能证明已取得原文。[浏览器采集决策](2026-10-23-browser-first-jd-collection.zh.md)约束采集方式，以及 JD 会话中拒绝匿名抓取和其他工具的执行拦截；通用预设仍为无关流程保留 `web_fetch`。精确的采集 URL 与逐字原文仍是图谱生成依据，取得原文不证明岗位持续有效。

Host 在其私有数据目录中保存版本化研究项目和采集原文。原子写入与写锁保护已提交修订，旧客户端不能覆盖其他写入者。原文和图谱版本只能追加，读写时都校验 SHA-256。Host 拒绝新增图谱引用当前已剔除的来源；历史图谱保留来源哈希。仅允许本机同源访问的 Connection 通道提供研究操作，与 Worker 发布及访谈存储独立。

搜索发现的登录受限地址保留为待采集来源。桌面端在隔离、持久化的浏览器会话中供用户亲自登录，再读取渲染后的岗位文本。外部页面没有原生接口；Cookie、密码和浏览器存储不进入研究文档或模型请求。可识别的登录页和截断 HTTP 结果不能证明取得了原文。浏览器和手工原文作为已记录的用户消息进入所属会话，供图谱生成使用；手工导入保留用户提供的来源标记。BOSS 列表 URL 可在地址不变时显示不同岗位，因此不能标识采集原文。读取器要求唯一的同源详情链接与显示岗位名称匹配，或使用独立详情页；归属缺失或存在歧义时拒绝采集。可见且包含职责的正文区域优先于偶然匹配类名的元素。

每条图谱分支遵循项目／任务／流程／技能点／知识点层级。每条引文须逐字存在于对应的已保留 JD 中。直接陈述需要逐字支持；归纳、工作流程及评价建议保留推断标记，须由专家复核。覆盖率按不同引文来源计数，不冒充市场总体需求占比或统计显著性。[已确认工作台决策](2026-10-23-confirmed-jd-workspaces.zh.md)说明搜索草稿、版本确认及 HTML 分发。导出使用已保存图谱与原文语料，不重新调用模型。

主要、次要及文件选择操作共用控件尺寸、字体和键盘焦点样式，以颜色区分操作优先级。操作组在工作台内换行。原生文件输入保留键盘激活和同文件重选能力。

## 考虑过的替代方案

**语法校验通过后直接信任模型来源链接。** 真实搜索曾返回与成功抓取页面不同的岗位编号。精确工具证据阻止这种不匹配成为可点击的结果。

**抓取失败时使用搜索摘要。** 搜索摘要可能缺少职责和日期。返回更少的已核验岗位或空结果，可以区分来源证据与推断。

**回退到其他可用对话。** 这样可能把 JD 请求和输出写入无关访谈。所属会话缺失时明确报错。

## 影响

真实搜索与分析使用用户已配置的模型和原生搜索提供者，产生普通提供者用量。公开网站可能报错、要求登录或更改内容；工作台不能保证目标条数或岗位仍有效。定向回归覆盖登录页误判成功、无依据引文、无效层级、并发写入、损坏的哈希，以及剔除后的历史证据。[桌面验收](../../../../apps/desktop/jd-research.acceptance.mjs) 使用真实桌面、Loader、模型适配器、搜索工具及浏览器采集与合成外部服务交互，验证登录后的续采、原文持久化、已确认 HTML 导出及重启恢复；其已提交输出快照可无密钥回放。合成服务不能证明真实平台兼容性或真实模型质量。平台限制、模型上下文容量及专家评审仍是重要约束。
