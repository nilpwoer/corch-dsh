# Agent Note: Worker 自有参与者口令

Status: implemented

[English](2026-10-15-worker-owned-invitations.md) | 中文

## Problem

客户端生成的六位口令使发布数据成为凭据权威来源，并让管理端缺少访问控制入口。合并的管理页还将当前题包设置与无关报告混在一起。

## Decision

新客户端不生成凭据，在传输 JSON 前要求 Worker 声明口令能力。经过认证的上传创建绑定不可变题包哈希的 160 位随机访问记录，唯一键插入使并发重试收敛到同一凭据。仅管理员可读取、禁止缓存的响应返回可恢复口令和片段分享地址，普通题包列表及参与者视图不返回口令。现有 MySQL 权限保护可恢复访问数据，不增加主密钥或管理员凭据。

既有题包口令是只读兼容来源，不因迁移、查看、上传或重试而回填或轮换。明确、带修订校验的管理员操作才可创建、轮换或撤销；撤销后不回退到旧题包口令。活跃参与者 Cookie 和冻结运行配置与邀请有效性分离。客户端将旧口令绑定原版本，后续口令只从权威回执展示。

题包编辑器、题包列表及报告页具有独立视图，仅获取自身数据。编辑器提供遮盖的口令控件及到其他视图的导航。公开入口保留服务端校验，不能通过公开读取接口取得预期口令。

## Alternatives considered

保留客户端生成会留下两个权威来源。为轮换改写发布 JSON 会改变不可变哈希及旧会话绑定。仅保存口令哈希无法支持稳定重试回执及授权后重复显示，这些消费者要求服务端可恢复保存。自动回填旧口令会在没有明确发布或管理意图时创建生产凭据记录。

## Consequences

版本 4 增加独立访问表，不回填凭据。新客户端拒绝旧 Worker 能力；旧客户端保留旧发布行为。版本 3 程序拒绝版本 4。[维护说明](../../../../worker/deploy/access-maint/README.zh.md)定义受保护的完整恢复边界及仅回退界面的版本 4 兼容程序，备份恢复不能安全丢弃迁移后的新写入。

隔离 SQL/HTTP 验收覆盖增量迁移、并发稳定回执、旧邀请、管理员可见性、无效及撤销口令、受保护回退。原生验收以合成数据覆盖两代客户端、独立设置和报告视图、片段链接复制、预填及明确点击进入，不调用模型。这些夹具不代表生产凭据初始化、麦克风或真实模型质量已验收。
