# Agent Note: 使用 MySQL 租约的 Go 教改 Worker

Status: implemented

[English](2026-10-11-go-teaching-worker.md) | 中文

## Problem

访谈追问和报告生成必须在 API 或消费者终止后继续执行，保留实际使用的指令，并拒绝已过时答案的结果。部署要求使用 Go 可执行文件、`serve -c` 启动、YAML 内配置提示词和 MySQL 存储。偶尔调整提示词不需要额外配置服务。

## Decision

[worker/](../../../../worker/README.zh.md) 是使用 Cobra 和 GORM/MySQL 的独立 Go 模块。可信后端向异步 API 提交已确认快照。API 和消费者可分开或合并运行，任务语义一致。现有 TypeScript 应用和 Cordis 循环属于独立调用方，不是隐式运行依赖。

MySQL 事务负责入队幂等、快照版本和报告冻结。短时 `SKIP LOCKED` 事务分配可续租的租约；发布及检查点写入要求认领令牌有效，且按数据库时钟租约未过期。模型请求在事务外执行。完成阶段持久化，但外部响应和检查点之间发生崩溃时可能重复付费调用。因此执行采用至少一次语义，并对发布校验认领令牌。

每个任务保存提示词、模型、服务商版本和执行限制。同一版本不可对应不同内容。访谈固定追问版本；新报告任务可基于冻结答案使用新的报告版本，同时保留先前报告。YAML 修改需重启，使配置发布明确可控。

所有运行参数，包括数据库凭据、后端令牌和模型密钥，均来自启动 YAML。模型密钥不进入版本快照及其哈希；消费者从当前配置解析凭据，并要求接口地址与版本记录的服务商一致。因此，轮换凭据不会修改历史提示词，也不会将凭据发送到排队任务中的不同地址。

可选的本地浏览器入口提供既有 SPA 资源，通过同源网关提交任务。签名 HttpOnly Cookie 将访问限定在各自访谈，不暴露共享后端令牌。数值回环监听地址、回环客户端及主机和来源检查将入口限定于本地调试；公开专家身份仍由应用负责。浏览器保存草稿和重试标识，MySQL 保存已接收快照与任务。

服务器部署使用 systemd 和不可登录的系统账号运行静态 Linux 二进制。Nginx 终止 HTTPS，将公网 `/teaching-worker/v1/` 前缀转换为 Worker 的 `/v1/` API。程序监听 Docker 网桥的宿主机网关，公网代理仅提供需鉴权的 API 及健康检查，服务器关闭本地浏览器网关。部署 YAML 与 Nginx 上游需使用相同网关和端口。

报告将逐字证据提取与生成分开。代码校验 JSON 字段、原文引述和引用 ID；提示词区分专家事实和解释。这些检查确保可追溯，不证明语义真实，也不保证抵御提示词注入。

## Alternatives considered

- 将 TypeScript Worker 放入插件运行时不符合独立 Go 部署要求，还会把队列可用性绑定到应用组装。
- PostgreSQL 队列库或 Redis 引入 MySQL 部署要求之外的存储系统。MySQL 租约可在访谈状态所在的事务体系内实现多消费者调度。
- 热更新提示词文件增加执行中行为的复现难度。明确版本并重启适合偶尔调整，无需配置控制服务。
- API 请求内同步调用模型无法独立于客户端连接和 API 生命周期；数据库事务内调用模型会在外部延迟期间占有锁。

## Consequences

后端 API 使用共享服务令牌，不管理专家身份。公开浏览器访问需要应用授权层。报告入队即冻结访谈，修改冻结答案需要另建访谈 ID。本地草稿同步、题目管理、保留期及删除、报告导出仍由应用负责。

[进程验收](../../../../worker/acceptance_test.go) 编译并运行实际可执行文件，连接真实 MySQL 和可控模型接口，验证进程终止后租约恢复、认领令牌拦截、版本及幂等冲突、阶段复用、消费者并发、报告不可变及重生成。组装后的交互记录具有无需密钥的黄金快照。真实服务商兼容性和报告语义质量属于独立验收要求，确定性样例无法证明这些能力。

[访谈 portal 决策](../feature/2026-10-13-worker-interview-portal.zh.md) 负责题包上传与公开访谈会话；本文继续负责 MySQL 租约及执行版本捕获。
