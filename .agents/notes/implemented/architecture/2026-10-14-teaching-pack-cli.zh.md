# Agent Note: 题包生成与本机导入

Status: implemented

[English](2026-10-14-teaching-pack-cli.md) | 中文

## 问题

题包生成与导出依赖浏览器组件状态，自动化客户端在浏览器控制不可用时无法产出同样经过校验的发布文件。复制凭据或构造替代问题会丢失真实 DSH 生成来源。

## 决策

仓库 CLI 通过现有回环地址 Host 会话接口创建新对话，检查已经选中的 DeepSeek 路由，将默认模型和凭据存储留给 Host。工作台和 CLI 共用问题解析、校验、元数据构建及发布导出逻辑。CLI 显式提供方法模板和参考材料，不读取浏览器 localStorage。真实会话标识和模型原文与不使用密钥的测试替身分开保存。

Worker 本机导入命令使用操作系统题包目录权限，并复用现有解析、可运行快照校验与原子不可覆盖发布器。Dry-run 只校验、不创建文件；相同导入幂等，冲突失败。命令不创建 HTTP 管理员会话，也不加载数据库或模型提供者配置；独立工具二进制不需要重启服务。

Node CLI 由 Client 聚合项目检查，因为它共享的题包模块属于 Client 项目；运行入口仍是 Node。传输子进程测试保留在 Host 聚合项目，专用 TypeScript 配置也可单独检查 CLI。

## 考虑过的替代方案

**自有进程 SDK：**官方 SDK 启动自己的运行时，不连接已配置的 Web Host。复用现有 Host 可避免复制凭据或争用其 home 状态。

**浏览器自动化：**不可用的浏览器控制基础设施不能作为可靠的命令接口；本流程明确不声称完成界面验收。

**直接复制文件或新增 HTTP 导入路由：**复制会绕过共用校验和冲突检查，新增网络路由则引入鉴权策略。本机命令通过已有 SSH 和操作系统授权复用发布约束。

## 影响

CLI 输出是具有可检查模型来源的真实 DSH 草稿，不是浏览器工作台记录。浏览器专属自定义内容需要显式转化为任务输入。模型失败和无效题包会阻止发布。含邀请码的产物保持私有，不写普通控制台输出。专门的传输入口、解析、发布和本机导入测试覆盖新增接口；真实模型生成作为独立执行校验。
